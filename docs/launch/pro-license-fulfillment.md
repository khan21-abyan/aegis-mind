# Aegis Mind Pro License — buyer instructions

## Fulfillment

This Pro license is issued individually and requires manual fulfillment. A license is not generated automatically by this download page. After purchase, contact the creator through your Gumroad receipt and include the purchase email and order details. The seller will provide a signed license file separately.

## Install

Place the received two-line license text in `.aegis/license.txt` in the directory where you run Aegis Mind. The license unlocks Pro multi-model failover-chain configuration (`AEGIS_FAILOVERS`).

The license does not add automatic server-side retries. Your agent's client loop executes retry and failover policies. Keep your license private; it is signed for offline verification on your machine.

## Requirements

- Node.js 20 or later
- Aegis Mind CLI installed with `npx aegis-mind`
- OpenAI-compatible upstream API configured for your agent
